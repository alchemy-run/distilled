# Get override codes (deprecated)

Deprecated

GET/accounts/{account\_id}/devices/{device\_id}/override\_codes

Fetches a one-time use admin override code for a device. This relies on the **Admin Override** setting being enabled in your device configuration. Not supported when [multi-user mode](https://developers.cloudflare.com/cloudflare-one/connections/connect-devices/warp/deployment/mdm-deployment/windows-multiuser/) is enabled for the account. **Deprecated:** please use GET /accounts/{account\_id}/devices/registrations/{registration\_id}/override\_codes instead.
