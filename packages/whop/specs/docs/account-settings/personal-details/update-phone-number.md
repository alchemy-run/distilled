# Update phone number

> Add or change the phone number saved on your Whop account from account settings.

You can add or change the phone number on file for your Whop account at any time. You will need to verify the number with a code sent by text message.

## How to add or update your phone number

1. Sign in to your account on Whop.
2. Go to [Account settings](https://whop.com/@me/settings/).
3. Select the **General** tab.
4. Find the **Phone number** field and select the pencil icon on the right to edit.
5. Enter your phone number and select the check mark on the right.
6. When the verification form appears, check your phone for a text message from Whop.
7. Enter the verification code from the text message.
8. Select **Save** at the bottom of the page.
