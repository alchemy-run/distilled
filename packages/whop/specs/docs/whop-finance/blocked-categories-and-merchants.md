# Blocked categories & merchants

> Merchant categories (MCCs) and merchants that Whop Cards block by default

Whop Cards block certain merchant category codes (MCCs) and specific merchants by default. Transactions matching these blocks are automatically declined during authorization. See [Card declines & risk rules](/whop-finance/card-declines-and-risk-rules) for how the system applies these blocks.

## Dynamically blocked merchants

Whop also proactively monitors merchants and blocks risky ones beyond the preceding default lists. Whop may remove these temporary blocks after the risk clears. The list changes continuously, so this page doesn't enumerate it.

Whop adds a merchant to the dynamic blocklist in three ways:

* **Proactive monitoring** — Whop automatically blocks merchants that show suspicious activity, typically on a rolling 24-hour window.
* **Dispute and fraud rates** — Whop blocks merchants with high dispute or refund rates, signs of compromise, or abuse by bad actors.

When one of these blocks declines a transaction, it's reported with a `blocked merchant` (or `blocked entity`) reason.

Because the dynamic list updates continuously, treat it as a moving target rather than a fixed set. If you believe Whop blocked a merchant in error, contact Whop support.
