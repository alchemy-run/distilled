# spec-mirror-hetzner

A git mirror of Hetzner Cloud's [OpenAPI spec](https://docs.hetzner.cloud/cloud.spec.json). The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-hetzner.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
