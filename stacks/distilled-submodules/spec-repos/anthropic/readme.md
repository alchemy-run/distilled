# spec-mirror-anthropic

A git mirror of the [Anthropic API](https://docs.anthropic.com/en/api) OpenAPI spec. The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

Anthropic has no stable public spec URL. Its SDKs are generated by Stainless, and each SDK repository recorded the spec it was built from as `openapi_spec_url` in `.stats.yml` — until 2026-09-03, when that key was removed from every SDK. The fetch script therefore:

1. checks `.stats.yml` at HEAD of [anthropic-sdk-typescript](https://github.com/anthropics/anthropic-sdk-typescript) and uses `openapi_spec_url` if Anthropic restores it;
2. otherwise falls back to the last published spec (2026-09-02, OpenAPI 3.1, 165 paths including the `/v1/organizations/*` Admin API):
   <https://storage.googleapis.com/stainless-sdk-openapi-specs/anthropic/anthropic-465bff21a179090915396565d1ae8f705cf8596e2ec920eb121072f25b8a7d68.yml>

The document is JSON despite the `.yml` name. Until a newer URL appears, the daily refetch produces no diff.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-anthropic.git
```

## Updating specs

From `.meta/`:

```sh
pnpm install
pnpm run fetch-specs
```
