# spec-mirror-huggingface

A git mirror of the Hugging Face Hub's [OpenAPI spec](https://huggingface.co/.well-known/openapi.json). The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-huggingface.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
