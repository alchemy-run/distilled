# spec-mirror-freestyle

A git mirror of Freestyle's [OpenAPI spec](https://api.freestyle.sh/openapi.json) ([freestyle.sh](https://www.freestyle.sh/docs)). The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-freestyle.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
