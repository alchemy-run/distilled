# spec-mirror-mux

A git mirror of Mux's [OpenAPI spec](https://www.mux.com/api-spec.json) for the REST API at api.mux.com. The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-mux.git
```

## Updating specs

From `.meta/`:

```sh
pnpm install
pnpm run fetch-specs
```
