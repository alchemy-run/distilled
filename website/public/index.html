How it works

Generated from the spec. Proven by Alchemy.

A spec is a claim about an API, and claims are wrong in the details. Distilled generates the SDK from the provider's own description, then Alchemy builds real infrastructure resources on top of it — creating, updating and destroying things against the live API. Every mismatch that surfaces becomes a patch to the spec, not a hand-edit to the code, and the next regeneration carries it forward.

What you get

Not a wrapper. Effect all the way down.

The generator does not emit fetch calls with types bolted on. Every operation is an Effect, so errors, pagination, configuration and bundling behave the way the rest of your program does.

01

Errors you can match on

Every failure the provider documents is a typed case.

catchTags is exhaustive; nothing arrives as unknown, and nothing has to be re-thrown. 

Effect.catchTag("CardError", retryWithBackupCard)
02

Pagination as a Stream

A listing is lazy until you pull from it.

Paginated operations expose .items(): take ten, filter, or run to completion — the pages fetch themselves. 

Lambda.listFunctions.items({}).pipe(Stream.take(10))
03

Configuration as Layers

Provide credentials once. Swap them in tests.

Credentials, region, base URL and the HTTP client are services, never arguments you thread by hand. 

Effect.provide(Credentials.fromEnv())
04

Tree-shakeable modules

Import one service, ship one service.

One S3 operation is 118 KB gzipped, not the whole of AWS. Runs on Node, Bun and Workers. See the numbers → 

import * as Zones from "@distilled.cloud/cloudflare/zones"
