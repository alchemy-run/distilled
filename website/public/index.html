@distilled.cloud  ·  packages  ·  Apache-2.0

Cloud APIs, distilled into Effect.

Every provider publishes a description of its API — OpenAPI, Smithy, GraphQL, a discovery document. Distilled reads that source and generates a typed, Effect-native TypeScript SDK from it. Nothing hand-written, nothing to drift.

How it works

From the provider's description to your import.

The SDK is a pure function of the spec. When a provider ships a new endpoint, the mirror moves, the generator runs, and the package follows. Fixes are RFC-6902 patches applied to the spec, so they survive every regeneration.

⊢ Errors you can match on

Every operation declares the errors the provider documents for it. catchTags is exhaustive; nothing is unknown. 

Effect.catchTag("CardError", retryWithBackupCard)

≡ Pagination as a Stream

Paginated operations expose .items(), so a listing is a lazy Stream you take from, filter, or run to completion. 

Lambda.listFunctions.items({}).pipe(Stream.take(10))

⧉ Configuration as Layers

Credentials, region, base URL and the HTTP client are services. Provide them once, swap them in tests, never thread them by hand. 

Effect.provide(Credentials.fromEnv())

∷ Tree-shakeable modules

Import the service you use — @distilled.cloud/aws/s3 — and the bundle carries only that surface. Runs on Node, Bun and Workers. 

import * as Zones from "@distilled.cloud/cloudflare/zones"
