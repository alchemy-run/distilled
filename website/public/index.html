@distilled.cloud

Effect-native SDKs for cloud providers

Distilled generates typed Effect SDKs from first-party API descriptions — OpenAPI, Smithy, GraphQL, discovery docs. One package per provider, committed and published, Apache-2.0.

View on GitHub

Install

Each provider is its own npm package. Pair it with effect: 

npm install @distilled.cloud/aws effect

Same shape for every provider: @distilled.cloud/cloudflare, @distilled.cloud/stripe, @distilled.cloud/github, …
